# AIクローラーへの方針(2026-07-23 Andy決定):
# 引用・参照してくれる相手には開き、持っていくだけの相手には閉じる。
# このサイトにあるのは音声とキュレーションへの案内板であり、守るべき本体(番組そのもの)は
# ここに置かれていない。参照されて名が届くことの方に価値がある。
#
# 除いた2つ:
#   Bytespider — robots.txtを無視した大量取得の実績があり、無料枠のCPUを脅かす
#   CCBot      — 一括再配布のアーカイブで、引用が返ってこない
#
# 非公開の口(編集室・放送卓・API・その日限りの生放送・検索)はどのクローラーにも開けない。

User-agent: Bytespider
Disallow: /

User-agent: CCBot
Disallow: /

User-agent: *
Content-Signal: search=yes, ai-train=yes, use=reference
# Disallowを先に置く: 「最も具体的な規則が勝つ」解釈(Google等)と
# 「先に一致した規則が勝つ」解釈(古典的な実装)の両方で同じ結果になるようにするため。
# Allow: / を先頭に置くと後者で非公開の口が開いてしまう(2026-07-23に実測で発見)
Disallow: /studio
# /deskは7/30のscribe→desk改名で「非公開の放送卓」と「公開のDesk Archive(/desk/日付)」が
# 同じ接頭辞に同居した。閉じるのは口だけ(=/desk本体と/desk/about=執筆画面)、
# アーカイブは開く(sitemapにも載せている公開ページ。塞ぐと日々の書き物が機械に一切届かない)。
# この3行の順序は上のDisallow先行の理屈と同じ: 先一致の実装でも
# /desk/aboutが先に閉じ、/desk/日付がAllowで開き、/desk本体が最後に閉じる
Disallow: /desk/about
Allow: /desk/
Disallow: /desk
# 共有カードの画像だけは開ける(2026-09-10)。番組ページ・エピソードページの
# og:image は /api/og-image を指していて、ここで塞ぐとXのカードに画像が出ない
# (Twitterbotはrobots.txtに従い、画像URLが塞がれているとサムネイルを出さない)。
# 対象は番組5+エピソード約330=sitemapで一番拾われてほしいページ群そのもの。
# リダイレクト先の /cdn-cgi/image/ は元から塞いでいないので、この1行で足りる。
# Disallowより前に置く: 上と同じく、先一致・最長一致のどちらの解釈でも同じ結果にするため
Allow: /api/og-image
Disallow: /api/
Disallow: /live
Disallow: /search
Disallow: /login
Allow: /
